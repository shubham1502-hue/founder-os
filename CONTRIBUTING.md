# Contributing

This repo is for practical founder/operator workflows.

Good contributions:

- new templates founders can copy
- better weekly review formats
- CRM field dictionaries
- startup metric examples
- Google Sheets or Notion versions
- segment-specific adaptations for SaaS, D2C, fintech, marketplace, or services businesses

Keep contributions practical. A founder should be able to copy, adapt, or learn from the change within 10 minutes.
